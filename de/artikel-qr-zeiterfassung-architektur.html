Wie QR-Zeiterfassung funktioniert: Architektur und Ablauf

Zusammenfassung: QR-based time tracking creates an attendance event when a valid code is scanned. A trustworthy system also handles authentication, timestamps, shift rules, exceptions, audit logs, and payroll transfer.

Kernablauf

  1. Code für einen Standort oder eine Schicht erzeugen.
  2. Mitarbeiter autorisieren und mit einem Mobilgerät scannen.
  3. Identität, Zeit, Standort und Gerätebedingungen prüfen.
  4. Eintritt, Austritt, Pause oder Schichtereignis speichern.
  5. Toleranz-, Schicht- und Fehlaufzeichnungsregeln anwenden.
  6. Freigegebene Daten an Zeiterfassung und Lohnabrechnung übertragen.

Ein QR-Code ist allein keine Sicherheit

Static or shared codes can enable proxy scanning. Use expiry, session, location, device, replay, and anomaly controls while keeping measures proportionate and avoiding unnecessary biometric surveillance.

Datenschutz und Lohnabrechnung

Collect only fields necessary for the defined purpose. Keep an exception queue for missing or conflicting events; every correction should record old value, new value, reason, user, and time.
